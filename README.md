# 💊 Pharmacy Management System

A web-based Pharmacy Management System developed using **Java, Spring Boot, HTML, CSS, JavaScript, and H2 Database**. The system helps manage medicine inventory, stock, sales, and transaction records through a user-friendly dashboard.

## 🚀 Live Demo

👉 **[Open Pharmacy Management System](https://pharmacymanagementsystem-conh.onrender.com)**

## ✨ Features

- 💊 Medicine inventory management
- 📦 Add and manage medicine stock
- 💰 Sales management
- 📋 Medicine and transaction records
- 🔗 REST API integration
- 📊 Web-based dashboard
- ☁️ Cloud deployment using Render

## 🛠️ Technologies Used

- **Java**
- **Spring Boot**
- **Spring Data JPA**
- **H2 Database**
- **HTML**
- **CSS**
- **JavaScript**
- **Maven**
- **Docker**
- **Render**
