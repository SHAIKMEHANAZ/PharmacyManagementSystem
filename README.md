# Pharmacy Management System

A web-based Pharmacy Management System developed using Java, Spring Boot, HTML, CSS, JavaScript, and H2 Database.

## 🚀 Live Demo

👉 https://pharmacymanagementsystem-conh.onrender.com

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- HTML
- CSS
- JavaScript
- Maven
- Docker
- Render

## ✨ Features

- Medicine inventory management
- Add and manage medicines
- Sales management
- Medicine records
- REST API integration
- Web-based dashboard
- Cloud deployment using Render
